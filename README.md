# About the Project

Sustainable App is an Android application developed as part of the final graduation project for the Computer Science program at Centro Universitário Sagrado Coração, in Bauru - SP, in the year 2022. The main objective of the app is to help, especially children, become more aware of recycling and its importance in the modern world.

During the development of the app, it was required to integrate content from three core subjects of the course. I chose to focus on the areas of Programming Languages, Databases, and Artificial Intelligence.

# Technical Information

This project was built using the MVVM architecture, the Xamarin Forms framework along with the C# programming language, SQLite as the database, and layout components from the SyncFusion package. It is an offline app, developed with the aim of demonstrating several mobile application features. The app stores data locally and utilizes native device components, such as the camera. It also features integration with YouTube to open videos externally and with Google Maps to display directions to recycling drop-off locations.

The application includes a theoretical ChatBot feature focused on recycling, which was chosen to be conceptual only for this project.

The app includes the following screens:

- A screen dedicated to the history of recycling, which includes a quiz with questions on the topic;
- A second screen that lists recycling drop-off locations in the city of Bauru, with an option for users to add new locations;
- A third screen where users can watch videos about recycling, as well as add new videos;
- A final screen with information about the project and course completion.

In addition to these, the app features login and user registration screens, recycling point and video registration forms, and quiz-related screens, including a results screen with personalized messages based on user performance.
